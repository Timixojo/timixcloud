## Deployment Architecture

Visitor
→ Cloudflare DNS & Proxy
→ HTTPS
→ AWS EC2
→ Nginx
→ TimixCloud static website

The origin server uses a Let's Encrypt TLS certificate managed by Certbot, with Cloudflare configured to use Full (strict) SSL/TLS encryption.
